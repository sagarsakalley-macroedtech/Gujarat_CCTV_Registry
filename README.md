Gujarat CCTV Registry
Centralised CCTV Registry and GIS Mapping Platform

The Gujarat CCTV Registry is a technology prototype developed under Model 01: Centralised CCTV Registry and GIS Mapping. The project provides a structured platform for maintaining and managing information related to CCTV infrastructure across government departments and districts.

The objective is to create a central registry where CCTV assets can be registered, organised and viewed through a single application. The platform also provides a foundation for GIS-based visualisation and future integration with CCTV health monitoring and other government systems.

Key Features
Centralised CCTV asset registry
Department-wise CCTV information
District-level infrastructure records
Camera registration and onboarding
Camera status management
Camera-level details
GIS-based CCTV mapping
Dashboard for infrastructure statistics
Automated database initialization and sample data seeding
